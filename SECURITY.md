# Секреты и безопасное использование

Не коммитьте API-ключи, Bearer-токены, token verifiers, `.env`, `.local`, private keys,
базы состояния, сырые prompts/ответы провайдера и архивы развёртывания. Общий
`.gitignore` исключает типовые каталоги и форматы; он не заменяет проверку содержимого.

Перед этой публикацией применён allowlist исходников, проверены новые файлы и
существующие Git blobs по известным локальным credentials и распространённым
форматам ключей. Совпадения в tests и day13/evaluate.py проверены: это синтетические
fixtures и общеизвестный AWS example, не рабочие credentials. Никакие реальные
значения или hashes действующих токенов в отчёт проверки не записывались.

Партнёр получает отдельный ограниченный токен приватно. Публичный API URL не
содержит авторизацию. При утечке сначала отзовите токен; удаление файла из новой
версии репозитория не удаляет его из истории, клонов и кэшей.

Используйте только собственные системы и согласованную область экспериментов.
Unit fixtures не дают разрешения атаковать сервисы. Если обнаружена возможная
утечка, не публикуйте её значение в Issue или PR; сообщите владельцу приватно.
