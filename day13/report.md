# Day 13 — отчёт

Реализация и VPS-развёртывание: 2026-11-08. Владелец настроил новый ключ и пароль. Один реальный запрос DeepSeek завершился HTTP 200: 75 входных + 39 выходных токенов, верхняя оценка стоимости $0.0000693. Остальные проверки синтетические. Результат: [live-smoke-result.json](live-smoke-result.json).

## Реализовано

- HTTPS UI и API за общим паролем, логин `day13`.
- Input Guard: блокировка/маскирование, паттерны ключей/PII, ограниченные преобразования.
- Output Guard: секреты, фрагменты system prompt, подозрительные URL/команды, проверка до выдачи.
- SQLite: резерв до вызова, аудит очищенного содержимого и метаданных отказов, восстановление unknown после рестарта.
- Лимиты: 10 попыток/мин/IP; $0.10/IP/30 минут; $1/global/24 часа; UI показывает остатки, резервы и освобождение бюджета.
- systemd encrypted credentials, dedicated runtime, ограничение памяти, loopback listener.

## Существенные исправления review

1. Глубина/количество декодирований теперь вызывают ENCODING_LIMIT вместо молчаливого пропуска.
2. Ошибочные URL блокируются; даже ошибка Output Guard завершает финансовый учёт, слот не зависает.
3. Откат восстанавливает nginx default/snippet/limiter и unit/release; старый сервис перезапускается. Каждая версия имеет отдельный venv.
4. Размер содержимого аудита считается в UTF-8 байтах. Лимит 20 MiB относится к текстам, служебные страницы SQLite и журнал транзакций добавляют накладные расходы.

## Оставшиеся ограничения

- Ключ и пароль настроены владельцем; сервис готов. Инструкция ротации: [README.md](README.md).
- Реальная интеграция проверена одним коротким запросом, без автоматических повторов. Это не нагрузочное испытание и не гарантия доступности провайдера. Проверочный бюджет $1 не превышен.
- Дата тарифа 2026-11-08; через 7 дней генерация выключается до проверки актуальности оператором. Peak estimate может быть выше реального off-peak счёта.
- Regex/эвристики не ловят любые секреты, перевод, шифрование и перефразирование system prompt. Есть ложноположительные срабатывания; сложные обфускации маскируются целиком.
- Секретов в system prompt нет. Администратор или скомпрометированный процесс могут прочитать ключ в runtime; encrypted storage от этого не защищает.
- Бюджет резервируется по консервативной оценке токенов: это не абсолютная гарантия биллинга провайдера. Превышение usage останавливает следующие вызовы.
- API POST не идемпотентен: после обрыва нельзя автоматически повторять. UI не повторяет запрос.
- Проверки интерфейса выполнялись в изолированном браузере.
